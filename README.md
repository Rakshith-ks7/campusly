# Campusly 🎓

> **College Student Community Platform** — Connect, collaborate, discover campus hubs, build AI teams, and bring collegiate projects to life.

---

## 🌟 Key Features

- **Multi-Student Authentication & Onboarding**: Email/password and Google Sign-In with personalized college profile setup.
- **Campus Hubs & Guilds**: Discover and launch specialized clubs (Coding, AI/ML, Exam Prep, Media, Robotics, Social & Startups).
- **AI Team Builder**: Form balanced hackathon and project teams using skills and interest weighting.
- **Student Directory & Connection Requests**: Follow peers, send collaboration invites, and build a campus network.
- **Real-time Messaging**: Direct student chats, unread counters, and instant notifications.
- **Campus Events & Hackathons**: Host and RSVP for campus workshops, guest lectures, and tech competitions.
- **Feedback & Admin System**: Student feedback categories (bugs, features, UI/UX) with administrative review.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend & Auth**: Firebase Authentication, Cloud Firestore
- **AI Matching Engine**: Python, FastAPI, Scikit-learn, Sentence Transformers

---

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18+)
- npm

### 2. Installation
```bash
npm install
```

### 3. Run Locally
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
